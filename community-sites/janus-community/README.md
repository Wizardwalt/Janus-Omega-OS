# Janus Community — Powered by Aria

Temporary staging location inside the Janus-Omega-OS ecosystem foundation repository.

This is a separate community website prototype, not part of the Janus OS application. It is intended to move unchanged or with minimal adaptation into the future standalone repository:

`Wizardwalt/Janus-Community`

Purpose: a practical technology community for electronics, computers, operating systems, networking, phones and device repair, diagnostics, software, maker projects, tutorials, and knowledge sharing.

No production authentication, user accounts, database, moderation service, analytics, or deployment is included yet. Keep this prototype static and independent. Do not couple its operation to Aria; Aria integration must be optional and permission-scoped.
