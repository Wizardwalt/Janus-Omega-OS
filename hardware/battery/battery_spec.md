# Project Mjolnir Battery System

## Cells
- 4x 21700 Li-ion Cells (High Discharge)
- Configuration: 2S2P (7.4V Nominal)

## Magazine Design
- Hot-swappable cartridge system.
- Pogo-pin interface for zero-latency swap.
- Integrated BMS (Battery Management System) for individual cell balancing.

## Charging
- Desktop "Forge" Dock compatible.
- 100W USB-C PD Charging.
