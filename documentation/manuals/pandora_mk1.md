# Pandora Mk.1: Instruction Manual

![Pandora Mk.1 Hero](images/pandora_mk1/hero.png)

### 1. OVERVIEW
The Pandora Mk.1 is a pocket-sized surgical tool for hardware-level security auditing. It specializes in USB glitching, voltage injection, and protocol manipulation.

### 2. HARDWARE INTERFACE
- **Core**: RP2040 Microcontroller.
- **Connector**: Gold-plated USB-C for maximum signal integrity.
- **Indicators**: RGB LED ring for status (Green: Safe, Red: Injection Active).
- **Control**: Single recessed tactical button for trigger execution.

### 3. OPERATION
- **FRP Bypass**: Connect to a target mobile device and launch the 'Alchemist' module.
- **Voltage Injection**: Use the precision clock to glitch memory controllers during boot.
- **Extraction**: Acts as a high-speed bridge for raw NAND dumps.

### 4. MAINTENANCE
- **Cleaning**: Keep the USB contacts dry.
- **Updates**: Flash new glitch patterns via the JanusOS terminal.
